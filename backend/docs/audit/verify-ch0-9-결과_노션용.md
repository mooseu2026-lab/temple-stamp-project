## 6. 저장소 실재

키가 있다는 것은 근거가 아니라는 원칙에 따라, **저장소에서 바이트를 도로 읽어** 확인했다(`StorageRealityTest` 5건).

| 무엇 | 확인한 것 |
|---|---|
| 사진 | 되읽은 바이트가 JPEG `FF D8 FF`·PNG 머리글로 시작한다 |
| 전자책 | `%PDF` 로 시작하고, 뽑은 텍스트에 한글·사찰명·인증서 번호가 들어 있다 |
| 인증서 | 저장소에서 읽히고, 그 안의 QR 을 디코드하면 진위 확인 주소가 나온다 |
| orphan 삭제 | 청소기가 지나간 키는 `getBytes` 가 예외를 던진다 — 큐에서 사라진 것과 파일이 사라진 것을 따로 본다 |
| presigned | URL 에 만료 시각이 실려 있고 서명이 그 시각에 묶여 있다(시각을 바꾸면 서명이 달라진다) |

한계 하나를 적어 둔다. 로컬 제공자에는 서명을 **검증하는** 쪽이 없어, 만료된 URL 이 거절되는지는 이 저장소로 잴 수 없다(운영 S3 는 검증한다). newman 의 E06 도 URL 모양까지만 본다.
