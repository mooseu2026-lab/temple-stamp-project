# ── 테스트 전용 더미 키 (2026-09-07 확인) ──
#   base64 를 풀면 각각 "jwt-secret-for-test-32bytes-minimum!" · "qr-secret-for-test-32bytes-minimum!!" 이다.
#   src/main 과 .env 어디에서도 쓰이지 않는다(grep 0건). JWT 서명 길이 요건(32바이트)을 채우려고
#   읽을 수 있는 문장을 그대로 인코딩한 값이다.
and0LXNlY3JldC1mb3ItdGVzdC0zMmJ5dGVzLW1pbmltdW0h
cXItc2VjcmV0LWZvci10ZXN0LTMyYnl0ZXMtbWluaW11bSEh

# ── 문서에 적힌 .env.local 작성 안내 (2026-09-07 확인) ──
#   값이 아니라 "이렇게 만드세요" 라는 예시다. 실제 값은 .env.local 에만 있고 그 파일은 커밋되지 않는다.
DB_PASSWORD=...
JWT_SECRET=$(openssl rand -base64 32)
QR_SECRET=$(openssl rand -base64 32)
STORAGE_SECRET_KEY=local-storage-secret
KAKAO_REST_API_KEY=

# ── 프론트 설계서의 비밀번호 "검증 규칙" (2026-09-07 C1 확인) ──
#   값이 아니라 Zod 스키마다 — "영문·숫자·특수문자를 섞어라" 라는 규칙을 적은 코드 예시다.
#   비밀번호가 적혀 있는 것이 아니라 비밀번호의 모양을 검사하는 코드다.
