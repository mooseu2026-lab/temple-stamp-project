# temple-stamp 백엔드 기능 총람 — 사용자 흐름 · 관리자 흐름 · 명세와 달라진 점 (2026-09-07)

챕터 0~10 기준(챕터 10은 진행 중, 반영 예정 표시). API 91 · 표 36(+챕터 10 컬럼) · 기능 58(+5).

## 1. 사용자 흐름 (순례자)

### 1-1 들어오기
| 단계 | 무엇이 되나 | API | 비고 |
|---|---|---|---|
| 관람 | 권역 10(제주 준비 중)·코스·사찰 상세 9블록·가는 법 7칸·오관게 5구·명상 108선 목록/재생·인증서 진위 확인 | 공개 17개 | 로그인 없이 |
| 가입 | 이메일·비번·닉네임·타겟(tier 7종, 기본 AGE30) | `POST /api/auth/signup` 201 | 이메일 소문자 정규화 |
| 로그인 | access 30분(메모리) + refresh **14일**(HttpOnly 쿠키, 챕터 10) · 회전 · 재사용 감지 시 전 기기 무효 · 5회 실패 15분 잠금 | `/api/auth/login·refresh·logout` | 로그아웃 200 |
| 설정 | 타겟·언어(ko/en/ja/zh)·알림·약관 동의/철회·**탈퇴**(비번 재확인, 즉시 익명화, 9단계 연쇄) | `/api/users/me` · `DELETE /api/users/me` 204 | 같은 이메일 재가입 가능 |

### 1-2 순례
| 단계 | 무엇이 되나 | API |
|---|---|---|
| 권역 → 코스 | 권역 9(코스 있는) → 코스(라인) 12 · 코스마다 자리 5(오관게 구 1~5) · 자리마다 후보 사찰 여러 곳(`congested` 표시) · 좌표 일괄 | `/api/regions` · `/api/courses` |
| 순례 시작 | 코스당 1건(멱등 200, `created` 플래그) | `POST /api/pilgrimages` |

| 싱글페이지 | 9블록 — 사찰·구절·**확장문구**(tier 축, 미노출 우선, 코스 내 version 중복 금지·챕터 10)·**행동과제**(tier 축, **사찰50/구절30/공통20 가중**·챕터 10)·뷰포인트·뱃지·라이더 정보·인증 상태·가는 법 여부 | `GET /api/sites/{id}/page` |

### 1-3 현장 인증 3단계 (순서 고정)
| 단계 | 무엇이 되나 | 실패 |
|---|---|---|
| ① GPS | 단말이 반경·정확도 판정 → 서버는 `siteId·withinRadius·accuracyGrade`만 받음(**좌표 필드 없음, 오면 400**) → 60분 세션 시작, QR 위치 힌트 | 반경 밖·정확도 LOW 400 |
| ② QR | 서명 토큰 + `qr_version` 회전(만료 없음) → 이 시점에 **미션 안내(원고)** 와 행동과제 id가 도장에 고정 | 다른 사찰·구버전 400 |
| ③ 미션 | 다짐 **10자~300자** + 사진 키(선택) → 도장 발행 → 응답에 진행률·보상·`courseCompleted`·인증서 번호·**도장 문구(EXT 원고)** | 60분 만료 409 · 슬롯 중복 409(사찰·날짜 포함) · 하루 5개 429 |
| 규칙 | 하루 5개(자정 Asia/Seoul) · 예외접수 하루 2건(사진 심사) · 사찰 간 최소 이동시간 미달이면 PENDING(관리자 심사) · 세션 만료는 청소기가 PK 배치로 | |

### 1-4 기록
| 무엇 | 규칙 | API |
|---|---|---|
| 사진 | 사찰당 1장 UPSERT + 문장 · `hasOtherFace`·`isPrivate` · presigned URL로 저장소 직접 업로드(서버는 바이트 안 받음) · 교체된 옛 파일은 삭제 큐 | `/api/uploads/presign` · `PUT /api/photos/{siteId}` |
| 생각상자 | 저장·조회·수정(sort date/course/site, `isPrivate`) · 점수·순위·답장 없음 · DELETE 204 | `/api/thinkbox` |
| 여섯 달 전 오늘 | 없으면 200 + null | `/api/thinkbox/flashback` |
| 명상 | 108선 목록·상세(비로그인)·재생 기록(로그인) · 로케일 폴백 | `/api/meditations` |

### 1-5 완주 → 인증서 → 보상 → 회향
| 무엇 | 규칙 |
|---|---|
| 완주 | 자리 5/5 발행 도장 → 재집계 멱등 → 인증서 자동 발행 · 반려 시 취소 연쇄(인증서 회수·GRANTED 보상만 회수·움직인 실물은 needs_review) · 재성립 시 인증서 새 번호·보상 같은 행 복귀 |
| 인증서 | 번호 `PG-yyyy-000000`(시퀀스 표, 중복 0, 재사용 없음) · 1장 조회 + **PDF(첫 조회 생성, QR 포함)** · REVOKED면 다운로드 없음 · **진위 확인 공개**(마스킹, 회수돼도 200+REVOKED) |
| 보상 | 규칙표 기준 적립(멱등) · `claimable` 서버 계산 · 실물 수령 신청(배송정보 별도 표, 목록 미노출) · 상태 GRANTED→CLAIMED→PAID/REJECTED |
| 회향 | ACTIVE 코스 전부 + 하한 12 → HH 인증서 + 회향 보상 |

### 1-6 전자책·인쇄
| 무엇 | 규칙 |
|---|---|
| 전자책 | 코스 완주 시 코스본 자동 큐 + **개인 소장본** 사용자 요청(스냅샷 해시 멱등, 하루 3권, READY 5권 상한) · 청소기가 5분 안에 PDF 생성(한글 폰트 임베드, 사진 1200px) · 비공개 생각상자 포함, **타인 얼굴 사진 제외(챕터 10)** · presigned 10분 다운로드 |
| 인쇄주문 | 본인 READY 책 전부 · 1~5부 · 배송정보 별도 표 · 사용자 취소는 REQUESTED만(`cancelable` 서버 계산·챕터 10) · 관리자 확인→인쇄→발송(송장)→완료 |

## 2. 관리자·편집자 흐름

| 역할 | 무엇 | API 묶음 |
|---|---|---|
| ADMIN 사찰·코스 | 사찰 UPSERT(카카오 장소 검색 → 좌표, 좌표는 이 경로만 허용)·status 필터·다국어·뷰포인트·뱃지·참배요소 · 코스 자리 5 배정 · 이동시간 표 · 코스 ACTIVE 전환 | 16 |
| ADMIN QR | 사찰별 QR 발급(PNG)·회전(+1로 일괄 무효) | 포함 |
| ADMIN 도장 심사 | PENDING(이동시간 미달·예외접수) 승인/반려 · 완료 도장 반려(COMPLETED↔REJECTED) → 완주 재집계 연쇄 | 포함 |
| ADMIN 완주·인증서·보상 | 재집계(1명·배치) · 인증서 회수(사유) · 보상 심사(needs_review 우선) | 5 |
| EDITOR 원고 | 등록(변형 ≤3, 금칙: URL·전화·이메일·HTML)·수정·제출·내 목록 | 4 |
| ADMIN 원고 심사 | 승인(4-eyes: 자기 원고 403)·반려(사유)·퇴역(삭제 없음) · CSV 일괄 반입(dryRun·파일 단위 원자성·시군구 대조) | 5 |
| ADMIN 콘텐츠(명세 체계) | 확장문구·행동과제 등록(구절×tier, 챕터 10부터 scope·사찰) | 4 |
| ADMIN 전자책·인쇄 | 인쇄주문 목록(배송정보 포함)·확인·인쇄중·발송·취소 · 전자책 재시도 | 3+ |
| ADMIN 운영 | 사용자 목록(DELETED 기본 제외) · 청소기 수동 실행(건수) | 2 |
| 운영 SQL(API 없음) | 역할 부여(EDITOR) · needs_review 해제 · 청소기 FAILED 복구 · 백업(mysqldump + 파일) | — |

청소기(5분): 파일 삭제 큐 100건(5회 실패 → FAILED) · 만료+24h 토큰 삭제(폐기-미만료 유지) · 전자책 생성 3건 · 세션 만료(PK 배치). 작업별 트랜잭션, 처리 건수 로그.
