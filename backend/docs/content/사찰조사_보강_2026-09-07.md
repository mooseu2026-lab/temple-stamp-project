## 4. 임의 입력 규칙 (예성 지시: "임의로 입력해두어라")
- 요금·시간·반려동물: DB 미기재. `checkedAt` 비움
- `mealAvailable`: 사찰음식 특화 확인 5곳(진관사·봉녕사·수도사·백양사·금수암·망경산사)만 `TEMPLE_MEAL`, 나머지 `NONE`
- 템플스테이: `description` 끝에 "템플스테이 운영(templestay.com)" 한 줄만
- 사진: `credits.json` 빈 뼈대, 파일 없음
