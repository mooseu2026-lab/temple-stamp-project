## 1. 프로젝트 한 줄
전국 사찰(조계종) 오관게 스탬프 순례 앱의 **백엔드 + 교재**를 동시에 만드는 프로젝트. 초6 학생 2명 팀프로젝트 형식이나 실제 서비스 수준. **예성(사용자)이 결정, Claude(나)가 정본·지시문 작성, Claude Code가 코딩·DB·검증 실행.** 예성의 손 작업은 파일 넣기·지시문 붙여넣기·마지막 줄 전달뿐.

- 스택: Spring Boot 3.5.16 · Java 21 · MyBatis 3.0.5 · MySQL 8(`time_zone=+09:00`) · jjwt 0.13.0 · zxing 3.5.4 · opencsv 5.9 · **OpenPDF 2.0.3 + Noto Sans KR(OFL 동봉)** · record DTO · Groovy DSL. 프론트(예정): React 18 + Vite + TS + Tailwind + TanStack Query + 카카오맵 JS SDK.
- 저장소: 루트 `C:\temple-stamp-project`(git **없음** → §7 GitHub 단계에서 생김). 소스 루트 `src/`, 문서 전부 `backend/docs/`(`spec/`·`textbook/`·`frontend/`·`audit/`·`verify/`·`정리.md`), `postman/`, 루트 `frontend/`는 비어 있음(FE-1 자리).

## 4. 확정된 핵심 결정 (새 창에서 다시 묻지 말 것)
- **편성 v4**: 9권역 × 5구 · 코스(라인) 12 · 자리 60 · 후보 사찰 110(`congested` 표시) · 회향 = ACTIVE 코스 전부 + 하한 12 · 슬롯당 도장 1.
- **인증**: access 30분 · **refresh 14일**(챕터 10) · 재사용 감지 전 기기 무효 · 5회 15분 잠금 · 탈퇴 즉시 익명화(유예 없음) · 관리자 대행 탈퇴 없음 · EDITOR 역할(부여는 SQL).
- **현장 인증**: 순서 고정 GPS→QR→미션 · 세션 60분 · QR 서명+회전(만료 없음) · 다짐 10자 · 하루 5·예외 2 · 이동시간 미달 PENDING.
- **두 콘텐츠 체계 병존**(챕터 10 §1): tier 체계 `expansion_phrase`·`mission`(싱글페이지 **확장문구·행동과제**, 50/30/20·미노출 우선·코스 내 version 중복 금지) ↔ 원고 체계 `manuscript`(사찰 축, **미션 안내·도장 문구**, 변형 ≤3, 4-eyes, CSV 반입). 같은 글이 나온다고 가정하지 않음.
- **완주·인증서·보상**: `progressOf` 한 곳 · 인증서 시퀀스 번호·회수 번호 재사용 없음·회수돼도 진위 확인 200+REVOKED · `CERT-4041` · 보상 GRANTED→CLAIMED→PAID/REJECTED·`claimable` 서버 계산·배송정보 별도 표 · 취소 연쇄는 GRANTED만 회수, 움직인 실물은 needs_review · 재성립 시 인증서 새 번호·보상 같은 행 복귀 · 중간본 INTERIM 없음.
- **전자책·인쇄**: 코스본 자동 큐 + 개인 소장본(스냅샷 해시 멱등·하루 3·READY 5권) · PDF만(EPUB 배포 후) · 비공개 포함·**타인 얼굴 제외** · 인증서 PDF 첫 조회 생성·QR이 정본 · 인쇄는 본인 READY 책 전부·1~5부·사용자 취소 REQUESTED만(`cancelable`) · 결제 연동 범위 밖.
- **청소기 하나**(5분): orphan 100·토큰 만료+24h·전자책 3·세션 만료 PK 배치, 작업별 트랜잭션, 단일 인스턴스 전제.
- **저장소**: local만 구현. prod에서 `storage.provider≠local`·`PUBLIC_BASE_URL=localhost`면 **기동 실패**. R2/S3는 챕터 11 후보.
- **명세 정정으로 닫은 것**: 상태코드 409/400 유지 · EXIF는 앱 책임 · `4040` 규칙 · 소셜 로그인 배포 후 · 원고 다국어 1차 범위 밖 · 명상 등록 API는 108편 채울 때.
- **문서**: 아무것도 지우지 않음(B안) · DELETE 5개 204 · 로그아웃 200 · 헬스 `/health`.
