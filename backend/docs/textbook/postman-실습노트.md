# Postman 실습 노트 — 챕터 0~3 전체 회귀 (2026-09-05)

> 실행자: 예성 · 도구: Postman 데스크톱(GUI) · 서버: `./gradlew bootRun` (localhost:8080, MySQL 기동 상태)
> 기록 규칙: 각 단계의 **결과** 칸에 `통과 n/n` 또는 실패한 요청 이름과 응답 코드를 적는다. 판단은 적지 않는다 — 판단은 표를 다 채운 뒤 §7에서 한 번에.
